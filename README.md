# Kotlin Algorithms

Здесь я собирал решения задач на Kotlin и небольшие упражнения, пока разбирался с языком. В некоторых задачах оставил несколько вариантов решения, чтобы сравнить подходы.

В репозитории есть:

- [Codewars](Codewars): 22 задачи уровней от 8 до 5 kyu, разложенные по папкам. Ссылки на условия находятся в исходниках.
- [Regex](Regex): 5 упражнений с регулярными выражениями, включая поиск чисел и email, проверку формата даты и IPv4.
- [Other/cli_sorting_kotlin.kt](Other/cli_sorting_kotlin.kt): консольная программа с обычной и адаптивной пузырьковой сортировкой, подсчётом итераций и времени.
- [src/Main.kt](src/Main.kt): примеры вызовов решений с выводом результатов в консоль.

## Запуск

Нужны JDK и компилятор Kotlin/JVM с командами `kotlinc` и `java` в PATH. Gradle и Maven в этом репозитории нет. Вместо командной строки можно создать Kotlin/JVM-проект в IntelliJ IDEA и добавить нужные исходники.

Для примеров Codewars и Regex из корня репозитория, в Bash:

```bash
kotlinc Codewars/kyu5/*.kt Codewars/kyu6/*.kt Codewars/kyu7/*.kt Codewars/kyu8/*.kt Regex/*.kt src/Main.kt -include-runtime -d algorithms.jar
java -jar algorithms.jar
```

Консольная сортировка запускается отдельно:

```bash
kotlinc Other/cli_sorting_kotlin.kt -include-runtime -d sorting.jar
java -jar sorting.jar
```

Введи целые числа через пробел, затем выбери команду из меню. Программа ожидает корректный числовой ввод. Сравнение времени здесь учебное, это не полноценный benchmark.

В `Main.kt` я выводил результаты через `println`. Автоматизированных тестов с assertions здесь нет. Репозиторий оставил как историю своей практики, без попытки превратить отдельные упражнения в библиотеку.
